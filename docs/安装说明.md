# 安装说明（待机时钟 · iOS StandBy 风格）

## 一、安装 APK

1. 获取 APK：`dist/待机时钟-v1.4.0.apk`（已签名，可直接安装），或在 Releases 下载。
2. 传到手机（数据线 / 微信 / QQ / 网盘均可），在文件管理器中点击安装。
3. 若手机上装过旧版本（1.0.0 起），直接覆盖安装即可（签名一致，数据保留）。
4. 若提示禁止安装：
   - 澎湃OS4：设置 → 安全 → 更多安全设置 → 安装未知来源应用 → 允许「文件管理/应用包安装程序」。
   - 通用安卓：设置 → 安全 → 未知来源应用（或按提示跳转）→ 允许。

## 二、首次使用四步走

1. **打开应用**，确认「启用待机模式」为开启状态。
2. **按顺序授权**（应用内权限面板会实时显示状态）：
   - 必做：省电策略（无限制）、自启动、后台弹出界面、锁屏显示、通知、悬浮窗。
   - 可选：日历（日历任务页）、定位（天气页）。
3. **验证**：点「立即预览待机时钟」，确认界面正常（黑底白色大时钟、可左右滑动三页）。
4. **真机触发**：插上充电器 → 手机**侧立横放**或**平放桌面（屏幕朝上）**→ 约 2 秒后自动全屏显示时钟。

## 三、日常使用

| 操作 | 结果 |
|---|---|
| 充电 + 侧立横放/平放朝上 | 自动显示全屏时钟 |
| 左右滑动 | 切换 时钟页 / 日历任务页 / 天气页 |
| 双击屏幕 | 手动退出（本次充电内不再自动弹出） |
| 拔掉充电线 | 自动退出，回到锁屏 |
| 拿起手机（竖放） | 自动退出，回到锁屏 |
| 解锁后再锁屏 | 屏幕点亮时自动重新弹出时钟 |
| 点击月历日期 | 查看当天日程 |
| ‹ › | 切换月份 |

## 四、如果没反应（排查顺序）

1. 打开「权限状态面板」，确认所有红色项已变绿（小米机型重点看：**自启动、后台弹出界面、锁屏显示、省电策略**）。
2. 进入「诊断信息」页：
   - 确认「监控服务：运行中」；
   - 看「实时检测」：插上充电线后应显示「充电：是」，把手机横放/平放后应显示对应放置姿态（可触发）；
   - 点「测试弹出时钟」验证弹窗链路；
   - 若仍有异常，把「最近异常记录」截图反馈。
3. 杀掉应用重新打开一次（首次授权后部分 ROM 需要重启应用生效）。
4. 若系统仍禁止后台弹出（部分 ROM 限制极严）：在设置页打开「悬浮窗备用模式」。

## 五、卸载

长按桌面图标 → 卸载（或 设置 → 应用设置 → 应用管理 → 待机时钟 → 卸载）。
