# 权限开启步骤（澎湃OS4 优先 · 兼容通用安卓）

> 应用内「权限状态面板」会自动检测每项权限，缺失项右侧有「去开启/去授权」按钮可一键跳转。
> 以下为手动路径，按顺序开启。**带 ★ 的为小米机型必开项。**

## 一、小米澎湃OS 4（HyperOS 4）

### ★ 1. 省电策略（电池不优化，最重要）
```
设置 → 应用设置 → 应用管理 → 待机时钟 → 省电策略 → 无限制
```
另一入口：`手机管家 → 省电与电池 → 右上角设置 → 应用智能省电 → 待机时钟 → 无限制`

### ★ 2. 自启动
```
设置 → 应用设置 → 授权管理 → 自启动管理 → 待机时钟 → 打开
```

### ★ 3. 后台弹出界面
```
设置 → 应用设置 → 应用管理 → 待机时钟 → 权限管理 → 后台弹出界面 → 允许
```

### ★ 3b. 锁屏显示（充电时在锁屏上弹出时钟的关键）
```
设置 → 应用设置 → 应用管理 → 待机时钟 → 权限管理 → 其他权限 → 锁屏显示 → 允许
```
> 若找不到该开关：设置 → 应用设置 → 应用管理 → 待机时钟 → 通知管理 → 锁屏显示 / 或在「权限管理」逐项查找。部分澎湃OS版本把该项归入「特殊权限」。

### ★ 4. 通知
```
设置 → 通知与控制中心 → 应用通知管理 → 待机时钟 → 允许通知（建议关闭"常驻通知"以外的骚扰项）
```

### 5. 悬浮窗显示
```
设置 → 应用设置 → 应用管理 → 待机时钟 → 权限管理 → 显示悬浮窗 → 允许
```

### 6. 日历（日历任务页需要）
```
设置 → 应用设置 → 应用管理 → 待机时钟 → 权限管理 → 日历 → 允许
```

### 7. 定位（天气自动定位需要，可选）
```
设置 → 应用设置 → 应用管理 → 待机时钟 → 权限管理 → 定位 → 仅在使用期间允许
```

### 8. 修改系统设置（可选）
```
设置 → 应用设置 → 应用管理 → 待机时钟 → 权限管理 → 其他权限 → 修改系统设置 → 允许
```

### 9. 锁定后台任务（防止一键清理杀掉监控）
```
打开待机时钟 → 进入最近任务 → 长按应用卡片 → 加锁
```

## 二、通用安卓（原生 / 其他 ROM）

| 权限 | 路径 |
|---|---|
| 电池优化白名单 | 设置 → 电池 → 电池优化 → 待机时钟 → 不优化 |
| 悬浮窗 | 设置 → 应用 → 特殊应用权限 → 显示在其他应用上层 → 待机时钟 → 允许 |
| 通知 | 设置 → 通知 → 应用通知 → 待机时钟 → 允许 |
| 日历 / 定位 | 设置 → 应用 → 待机时钟 → 权限 → 允许 |
| 修改系统设置（可选） | 设置 → 应用 → 待机时钟 → 修改系统设置 → 允许 |

## 三、无需授权的项目（说明）

| 项目 | 说明 |
|---|---|
| 读取电池电量 | 安卓系统接口（BatteryManager），无需任何授权 |
| 重力传感器 | 系统传感器接口，无需任何授权（未检测到重力传感器时自动回退加速度计） |
| 窗口级亮度调节 | 本应用通过 Window 属性调节时钟窗口亮度，**不需要**"修改系统设置"权限；该权限仅在需要调节全局系统亮度时才有意义 |

## 四、其他品牌手机提示

- **华为 / 荣耀（HarmonyOS/EMUI）**：设置 → 应用 → 应用启动管理 → 待机时钟 → 手动管理（开启自启动、关联启动、后台活动）。
- **OPPO / 一加（ColorOS）**：设置 → 应用 → 自启动；电池 → 更多设置 → 应用耗电管理 → 待机时钟 → 允许完全后台行为。
- **vivo / iQOO（OriginOS）**：i管家 → 应用管理 → 权限管理 → 自启动/后台弹出界面；电池 → 后台耗电管理 → 允许后台高耗电。
- **三星（One UI）**：设置 → 电池 → 后台使用限制 → 未限制；智能管理器 → 自动运行应用。
